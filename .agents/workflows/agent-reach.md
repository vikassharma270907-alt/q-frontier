# Workflow: agent-reach

Follow the `agent-reach` skill to search, extract transcripts, fetch discussions, or read links from supported platforms:

- Web reading & search: `agent-reach web search "<query>"` or `agent-reach read "<url>"`
- YouTube subtitles & info: `agent-reach youtube subtitle "<video_url>"` or `agent-reach youtube search "<query>"`
- GitHub repo, PR, and issues: `agent-reach github read "<owner/repo>"`
- Discussions & Social: `agent-reach reddit search "<query>"`, `agent-reach v2ex hot`, `agent-reach twitter search "<query>"`
- Platform capabilities & diagnostics: `agent-reach channels` or `agent-reach doctor --text`
