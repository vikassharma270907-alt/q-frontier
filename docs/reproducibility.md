# Q-FRONTIER: Reproducibility Protocol & Audit Specification

**Version:** 2.0.0  
**Standard:** Open Science & Auditable Quantum Computing  

---

## 1. Guiding Principles

Every claim, metric, and figure generated by Q-FRONTIER must be independently reproducible on standard hardware without network dependencies or proprietary credentials:
1. **Deterministic Seeding:** All synthetic price generators and stochastic optimizers accept explicit random seeds.
2. **Cryptographic Data Fingerprinting:** Every input dataset is hashed using SHA-256 to ensure exact bit-for-bit input integrity.
3. **Immutable JSON Audit Bundles:** Benchmark outputs can be exported with complete execution metadata, environment specifications, solver parameters, and ground truth references.
4. **Offline Execution:** The application bundles deterministic synthetic presets and local caching, requiring zero internet access to run.

---

## 2. Cryptographic Data Fingerprinting

Before executing any benchmark run, the backend hashes the normalized price series:

```python
import hashlib
import pandas as pd

def fingerprint_prices(df: pd.DataFrame) -> str:
    csv_bytes = df.to_csv().encode("utf-8")
    return hashlib.sha256(csv_bytes).hexdigest()[:16]
```

This 16-character SHA-256 hex string uniquely identifies the dataset and is embedded in all run records and export bundles.

- Median objective value
- Interquartile Range (IQR = $Q_3 - Q_1$)
- Minimum and Maximum objectives

## 5. Step-by-Step CLI Reproduction Guide

### Prerequisites
- Python 3.11+
- Node.js 18+ (for frontend dashboard)

### 1. Run Backend Unit & Integration Tests
```bash
pytest
```
Verifies all 32 tests pass including covariance properties, Dicke state properties, XY mixer commutation, and exact enumeration agreement.

### 2. Launch Local API & Dashboard
```bash
uvicorn app.main:app --port 8000
```
Open [http://localhost:8000](http://localhost:8000) in your web browser. The entire application (API + React dashboard) is served seamlessly on port 8000.

### 3. Trigger Benchmark via cURL
```bash
curl -X POST "http://localhost:8000/api/runs" \
  -H "Content-Type: application/json" \
  -d '{
    "dataset_id": "synthetic_nasdaq_8",
    "asset_count": 8,
    "k_cardinality": 3,
    "lambda_risk": 0.5,
    "covariance_method": "ledoit_wolf",
    "solvers": ["exact", "annealing", "xy_qaoa", "ccd_qaoa", "penalty_qaoa"],
    "circuit_depth": 1,
    "seeds": [42, 101, 777]
  }'
```

### 4. Direct QPU Hardware Execution via cURL
```bash
curl -X POST "http://localhost:8000/api/hardware/execute-qpu" \
  -H "Content-Type: application/json" \
  -d '{
    "backend_target": "ionq",
    "n_qubits": 4,
    "k_cardinality": 2,
    "circuit_depth": 1,
    "shots": 1024
  }'
```

### 5. Download Export Bundle
```bash
curl "http://localhost:8000/api/runs/{run_id}/export" -o reproducibility_bundle.json
```
